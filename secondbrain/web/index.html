    How Adaptive Memory works

    1. Session ends — transcript is collected from the checkpointer
    2. Extract — Gemini pulls durable facts (max )
    3. Match — similar memories found (≥ )
    4. Judge — SAME / CONTRADICTS / UNRELATED
    5. Update — new fact stored, contradicted one deprecated
